OptimizadorMacM4

Monitor de recursos M4, gestor de procesos en background y limpieza segura de cachés para macOS.

Descargar versión 0.0.1

Elige el formato de instalación. No requiere dependencias externas: la app es nativa Swift.

OptimizadorMacM4.dmg Arrastra la app a Aplicaciones. Recomendado para probar rápido.
DMG
OptimizadorMacM4.pkg Instalador con comprobación de macOS 14+ antes de instalar.
PKG

Requisitos

  • macOS 14.0 (Sonoma) o superior
  • Mac con Apple Silicon (M1/M2/M3/M4)
  • No requiere Xcode ni Homebrew para usar la app instalada

Instalación

  1. Descarga el DMG o el PKG.
  2. Con DMG: abre el disco, arrastra OptimizadorMacM4.app a Aplicaciones.
  3. Con PKG: ejecuta el instalador y sigue los pasos.
  4. La primera vez, macOS puede pedir confirmación en Ajustes → Privacidad y seguridad.
